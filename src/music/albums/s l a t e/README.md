# s l a t e

Taruh file lagu album ini langsung di folder ini. Player akan mendeteksi file audio otomatis saat build—tidak perlu mengedit daftar/manifest lagu.

Format yang didukung: `.mp3`, `.m4a`, `.ogg`, `.wav`, `.aac`.

Nama file menjadi judul lagu. Awalan nomor urut seperti `01 - ` akan dihilangkan dari judul yang ditampilkan. Untuk album lain, buat folder baru di `src/music/albums/` dan letakkan semua lagunya di dalam folder tersebut.
